# مختبر اكتشف الافتراضي

موقع عربي RTL ثابت لدرس التفاعل الكيميائي ودلالاته، العلوم والحياة للصف الثامن الفلسطيني، الفصل الثاني، الصفحات المطبوعة ٨–١٤. المصدر العلمي الوحيد هو ملف صفحات الدرس الذي أرفقه المستخدم. لم تُضمّن الصورة الشخصية لعدم طلب استخدامها.

## التشغيل
من جذر المستودع: `python3 -m http.server 8000 --bind 0.0.0.0` ثم افتح الموقع في متصفح. لا تثبيت أو build أو أسرار مطلوبة. يُفضّل HTTP بدل فتح ملف HTML مباشرة لاكتشاف التسجيلات.

## المحتوى
الغلاف، الميزان، الخارصين والبالون، المفهوم، المعادلات (الكالسيوم وكربونات البوتاسيوم والأمونيا)، أنشطة الحرارة واليود والراسب والملفوف والمغنيسيوم، اختبار من سبعة أسئلة وشهادة قابلة للطباعة. تقدم الجلسة مؤقت، ويُعاد عند تحديث الصفحة. كل التجارب رقمية ولا تتضمن تعليمات منزلية لتنفيذ التجارب الخطرة. مؤشر الحرارة نوعي وليس قياسًا عدديًا.

## الصوت
راجع assets/audio/README.md لإضافة تسجيلات MP3. زر تجربة تسجيلك لا يرسل الملف لأي جهة. جودة وتوفر القراءة الآلية العربية يعتمدان على الجهاز.

## GitHub Pages
ارفع إلى main ثم في Settings → Pages اختر Source: GitHub Actions. يتولى workflow المرفق النشر عند push إلى main. تفعيل Pages وصلاحيات Actions يحتاجان إعدادات مالك المستودع؛ لا يُعد رفع الملفات دليلًا على نجاح النشر. جميع مسارات الملفات نسبية وتعمل تحت /sciencelab/.

## التحقق
يتطلب اختبار المتصفح Playwright وChromium مثبتين خارج المشروع. شغّل الخادم ثم `node tests/smoke.cjs` مع إتاحة حزمة playwright عبر NODE_PATH عند الحاجة. يمكن تخصيص CHROMIUM_PATH وTEST_URL. يغطي الاختبار الموازنة والمحاكاة والمقارنات والتغذية الراجعة والاختبار والشهادة ورفع تسجيل WAV محلي وتشغيله وإيقاف الصوت عند التنقل، والعرض بعرضي 390 و1280 بكسل. القراءة الآلية اختُبر مسار طلبها ورسائلها، لا جودة نطق عربي مسموع. نجاح الاختبارات لا يثبت نشر GitHub Pages.
