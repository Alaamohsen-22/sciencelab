# مختبر اكتشف الافتراضي

موقع عربي RTL ثابت لدرس التفاعل الكيميائي ودلالاته، العلوم والحياة للصف الثامن الفلسطيني، الفصل الثاني، الصفحات المطبوعة ٨–١٤. المصدر العلمي الوحيد هو ملف صفحات الدرس الذي أرفقه المستخدم. يتضمن الغلاف صورة توضيحية مولّدة مستوحاة من الصورة المرجعية التي قدّمها المستخدم، وليست صورة فوتوغرافية أصلية.

## التشغيل
من جذر المستودع: `python3 -m http.server 8000 --bind 0.0.0.0` ثم افتح الموقع في متصفح. لا تثبيت أو build أو أسرار مطلوبة. يُفضّل HTTP بدل فتح ملف HTML مباشرة لاكتشاف التسجيلات.

## المحتوى
الغلاف، تمهيد لغز العالم الصغير، اختبار قبلي مستقل من أربعة أسئلة، أهداف الدرس، الميزان، الخارصين والبالون، المفهوم، المعادلات (الكالسيوم وكربونات البوتاسيوم والأمونيا)، أنشطة الحرارة واليود والراسب والملفوف والمغنيسيوم، اختبار من سبعة أسئلة وشهادة قابلة للطباعة. تقدم الجلسة مؤقت، ويُعاد عند تحديث الصفحة. كل التجارب رقمية ولا تتضمن تعليمات منزلية لتنفيذ التجارب الخطرة. مؤشر الحرارة نوعي وليس قياسًا عدديًا.

## الصوت
تسجيلات المعلمة الحقيقية فقط بصيغة MP3 أو WAV، ولا تصدر الصفحة صوتًا عند غياب التسجيل. راجعي assets/audio/README.md لأسماء الأقسام السبعة الثابتة. اختيار ملف من الجهاز للتجربة محلي للجلسة ولا يرفعه؛ النشر الدائم يكون بإضافته إلى المستودع. يمكن التشغيل والإيقاف المؤقت وإعادة الاستماع. يتوقف الصوت عند التنقل ولا يبدأ تلقائيًا.

## GitHub Pages
ارفع إلى main ثم في Settings → Pages اختر Source: GitHub Actions. يتولى workflow المرفق النشر عند push إلى main. تفعيل Pages وصلاحيات Actions يحتاجان إعدادات مالك المستودع؛ لا يُعد رفع الملفات دليلًا على نجاح النشر. جميع مسارات الملفات نسبية وتعمل تحت /sciencelab/.

## التحقق
يتطلب اختبار المتصفح Playwright وChromium وFFmpeg مثبتة خارج المشروع. شغّل الخادم ثم `node tests/smoke.cjs` مع إتاحة حزمة playwright عبر NODE_PATH عند الحاجة. يمكن تخصيص CHROMIUM_PATH وTEST_URL. يغطي الاختبار الرحلة الجديدة والاختبارين واستقلال نتيجتيهما والمحاكاة والشهادة والتنقل، وغياب الصوت دون ملف وتشغيل التسجيل المحلي والملف المنشور والإيقاف المؤقت والإعادة، والعرض للهاتف والكمبيوتر. نجاح الاختبارات لا يثبت نشر GitHub Pages.

## المختبر الرقمي التفاعلي
تأتي صفحات مفهوم التفاعل والميزان والموازنة قبل مختبر الخارصين، ثم بقية المحاكاة. يجهّز الطالب اللغز الرقمي بالضغط على الأدوات أو سحبها إلى الدورق؛ أزرار الأدوات تدعم اللمس ولوحة المفاتيح أيضًا. الترتيب داخل اللعبة: الخارصين، الحمض المخفف، البالون. تبدأ الرسوم فقط بعد الخطوة الثالثة، وتظهر رسائل تصحيح لطيفة عند الخطأ. هذا ترتيب للغز رقمي وليس تعليمات لتجربة حقيقية. زر إعادة التجربة يمسح التجهيز والملاحظات ويلغي أي مؤقت جارٍ. شخصية الطالب SVG صغيرة ولا تتداخل مع عناصر التحكم.

مشغل التسجيلات يظهر مباشرة أسفل عنوان الصفحة وقبل محتواها؛ أسماء التسجيلات السبعة ثابتة كما هي موثقة في assets/audio/README.md. توسّعت الاختبارات لتغطي السحب والإفلات والضغط ولوحة المفاتيح واللمس الفعلي في سياق هاتف، ومنع التفاعل قبل اكتمال الترتيب وإعادة الضبط وموضع المشغل.

## تجهيز جميع التجارب
تمتد إضافة المواد يدويًا إلى التمهيد وجميع التجارب، مع شخصية الطالب نفسها بجانب كل منطقة عمل. يمكن الضغط أو استخدام لوحة المفاتيح أو السحب والإفلات؛ الضغط باللمس متاح للهاتف. تختلف الإضافات حسب التجربة: ألمنيوم وملقط خشبي وحمض مخفف، خبز أو حليب ثم اليود، ملح وماء وتحريك ونترات الفضة، وسط حمضي أو قاعدي ثم كاشف الملفوف المُحضّر، ومغنيسيوم وصنفرة وملقط وتسخين افتراضي. المشاهد تستخدم الوعاء أو السطح المناسب بدل فرض دورق واحد على جميع الأنشطة.

اختيار عينة أو وسط جديد يعيد تجهيز التجربة ويخفي التفسير السابق. زر إعادة التجربة يلغي أي نتيجة منتظرة؛ لا يبدأ التصحيح العلمي حتى اكتمال المحاكاة. جميع الخطوات ألغاز رقمية وليست إرشادات للتنفيذ الحقيقي. تشمل اختبارات المتصفح جميع العينات بالضغط والسحب واللمس وإعادة الضبط.

## تمهيد «كيف تكوّن الصدأ؟»
حلّ نشاط الصدأ محل لغز الخارصين في صفحة التمهيد فقط. يضيف الطالب الماء ثم يعرّض المسمار للهواء ويضغط «مرور الوقت». تظهر طبقة الصدأ البنية المحمرة على أربع مراحل زمنية توضيحية؛ المحاكاة تسرّع الزمن ولا تدّعي أن الصدأ يتكوّن فورًا. يظهر سؤال عن تكوّن مادة جديدة، ثم تفسير الصدأ وتعريف التفاعل الكيميائي وفق الدرس بعد الإجابة الصحيحة مباشرة في الصفحة نفسها. يبقى الشرح اللاحق مرجعًا للمتابعة، والمختبر الرئيسي وسائر التجارب كما هي. يستخدم التمهيد تسجيل `welcome` الحقيقي فقط.
