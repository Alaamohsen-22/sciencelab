# تسجيلات المعلمة الحقيقية فقط

لا يحتوي الموقع على أصوات اصطناعية أو مؤثرات صوتية أو تسجيلات جاهزة. عند غياب تسجيل يبقى الشرح مكتوبًا ولا يصدر صوت.

ضعي تسجيلك بصيغة MP3 أو WAV في هذا المجلد، بالأسماء التالية:

| الاسم (دون الامتداد) | القسم |
| --- | --- |
| welcome | الترحيب على الغلاف والتمهيد التفاعلي |
| goals | أهداف الدرس |
| concept | مفهوم التفاعل الكيميائي |
| reactants | المواد المتفاعلة والناتجة ونشاط الميزان |
| balancing | المعادلات الكيميائية وموازنتها |
| activities | أنشطة الخارصين ودلالات التفاعل (شرح جامع للأنشطة) |
| closing | التعليمات الختامية والاختبارات والشهادة |

مثال: `welcome.mp3` أو `welcome.wav`. إن وُجد الامتدادان يُستخدم MP3 أولًا. الأسماء ثابتة ولا تتغير بتغيير ترتيب الصفحات. كل صفحة تعرض مشغل قسمها مع تشغيل وإيقاف مؤقت وإعادة الاستماع وضوابط المتصفح.

للتجربة: اختاري تسجيلًا من الجهاز في مشغل القسم؛ يتاح لنفس القسم حتى الانتقال بين صفحاته، طوال الجلسة الحالية. لا يرفع الملف إلى أي خادم ولا يبقى بعد تحديث الصفحة. للنشر الدائم أضيفي ملفات التسجيل إلى GitHub ثم انتظري نجاح نشر Pages. لا يتطلب الموقع تسجيلًا للدخول أو ميكروفونًا ولا يسجل صوتًا تلقائيًا.
