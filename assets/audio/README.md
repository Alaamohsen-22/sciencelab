# التسجيلات الصوتية

ضع ملفات MP3 هنا باسم `رقم-المحطة-رقم-الفقرة.mp3`، بأرقام إنجليزية تبدأ من الصفر.
مثال: `0-0.mp3` أول شرح في محطة الميزان، `0-1.mp3` الشرح الثاني؛ `4-0.mp3` مقدمة نشاط الحرارة و`4-1.mp3` تفسيره. المحطات: 0 الميزان، 1 الخارصين، 2 المفهوم، 3 المعادلات، 4 الحرارة، 5 اليود، 6 الراسب، 7 الملفوف، 8 الوميض.
كل فقرة شرح لها مشغّل مستقل. يبحث زر الاستماع عن MP3 ثم يستخدم قراءة المتصفح العربية عند غيابه. يمكن تجربة ملف محلي دون رفعه، ويظل اختياره حتى إعادة تحميل الصفحة. لا تتضمن النسخة تسجيلات بشرية جاهزة. يتطلب الصوت الآلي دعم المتصفح وصوتًا عربيًا مثبتًا.
