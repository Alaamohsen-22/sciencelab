# مؤثرات أصلية للموقع
هذه النغمات الآلية القصيرة أُنشئت خصيصًا لهذا المشروع بواسطة generate.py (دون أصوات بشرية أو كلام). متاحة وفق CC0 1.0، ويمكن إعادة توليدها باستخدام Python دون حزم إضافية.

- success.wav: نغمة نجاح 1.60 ثانية.
- error.wav: نغمة تصحيح هادئة 0.30 ثانية.
- click.wav: نقرة خفيفة 0.09 ثانية.

الملفات PCM WAV أحادية القناة 22050 Hz، وحجمها الإجمالي أقل من 90 KB. مدير effects.js يشغّل مصدر مؤثر واحدًا في كل لحظة ويمنح النجاح أولوية على النقر. زر الكتم مخصص لهذه المؤثرات ولا يكتم تسجيلات المعلمة في assets/audio.
