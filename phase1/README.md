- لم يُثبت خطأ علمي يستدعي تغيير المحتوى الأصلي أثناء العمل؛ أي تصحيح علمي لاحق يحتاج مراجعة المعلمة.

## التنفيذ

- `core/immersive-phase1.js`: خريطة مختبر بثلاث بوابات SVG شبه ثلاثية الأبعاد، حالة آخر محطة زارها الطالب، انتقال باب قصير لا يؤخر تنفيذ زر الدخول ولا تشغيل الأغنية، مؤشرات المحطة، تكبير رسوم الإنفوجرافيك في حوار يمكن إغلاقه بـEscape، محاور قابلة للتوسيع تحفظ النصوص الأصلية، وضع هدوء الحركة.
- `core/immersive-phase1.css`: نظام موحد بالألوان المطلوبة، عمق وإضاءة وتطريز خفيف وأغصان زيتون، خلفية علمية متحركة، تنقل واضح، أسطح تجارب محسنة، تنسيق مختلف لخرائط الدروس الثلاثة، زخرفة للشهادات المعروضة والطباعة/PDF.
- `core/discovery-facts.js`: اثنتا عشرة معلومة قصيرة موثقة، تُعرض معلومة واحدة اختيارية لكل صفحة. أثناء الاختبار يُستخدم اختيار من معلومات التاريخ العلمي والبيئة والقياس، دون إجابات الأسئلة أو أي ارتباط بالدرجات. الرسوم المرافقة توضيحية وليست صورًا توثيقية.
- تتسع منطقة المحتوى على الشاشات الواسعة لتظهر النافذة إلى جانبها دون تضييق مساحة التجربة الأصلية. على الهاتف واللوحي والشاشات المتوسطة تظهر نافذة صغيرة قابلة للفتح فوق المحتوى.
- تستمر أدوات التنفيذ والسحب والبدائل بالضغط وأسئلة التوقع والملاحظة والاستنتاج والتقويم الأصلية. لم يُضف تسجيل دخول أو شرط لفتح الدروس.
- تستمر الشخصية الموحدة والمساعدة السياقية والاستماع الحالي. لا طلبات ElevenLabs ولا توليد أصوات أو ملفات جديدة ولا استهلاك Credits.
- `data-reward-slot` يجهز مكانًا فارغًا للمرحلة الثانية؛ لا أوسمة مكتسبة وهمية، ولا نقاط أو اقتصاد نجوم جديد. مؤشر الزيارة ليس دليل إتقان.

## التصميم التعليمي

تحليل: حصر المحتوى والأجهزة والقيود وتثبيت نسخة استعادة. تصميم: إبقاء تسلسل الدرس والاستقصاء مع فصل الإثراء الاختياري عن التقويم. تطوير: طبقة عرض قابلة لإعادة الاستخدام بدل إعادة كتابة المحاكاة. تنفيذ: فرع مراجعة مستقل بلا نشر. تقويم: مقارنة محتوى، وفحوص تفاعل واستجابة ولوحة مفاتيح وطباعة.

## حدود مقصودة ومراحل لاحقة

- التمثيل شبه ثلاثي الأبعاد عبر SVG/CSS؛ لم تُضف مكتبة WebGL كبيرة أو أجهزة تحكم تجوال معقدة. رسوم المحطات زخرفية، وليست بديلًا للرسوم العلمية الدقيقة داخل التجارب.
- حركات المعلمة للصورة والإطار والتعبير البصري؛ لا توليد لملامح جديدة أو تحريك جسدي واقعي مزعوم. الصورة الأصلية لم تمس.
- خيار «حركة هادئة» يقلل انتقالات الواجهة، وتحترم الواجهة أيضًا إعداد الجهاز. المحاكاة العلمية تحتفظ بأزرار الإيقاف والمتابعة وآليتها الأصلية.
- تغيير الزخرفة يخص عرض الشهادات والطباعة/PDF. تنزيل PNG الأصلي ووظيفته ومحتواه محفوظة كما هي، ولا يوجد ادعاء اعتماد رسمي.
- اختبارات الهاتف محاكاة لمس في Chromium، وليست فحص أجهزة فعلية أو Safari. على الشاشات القصيرة أو عند تكبير الرسم قد يبقى التمرير ضروريًا.
- إنتاج الصوت الجديد وربط النجوم والأوسمة مؤجلان للمرحلة الثانية. لم تُنشر هذه النسخة على Pages.
